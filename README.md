UberFix 

📖 نظرة عامة
UberFix هو نظام متكامل لإدارة طلبات الصيانة مصمم خصيصاً للسوق المصري، يوفر منصة شاملة لربط العملاء بالفنيين وإدارة جميع عمليات الصيانة من البداية للنهاية.                    هذه المنصّة تابعة لشركة العزب المعمارية المسجّلة كشركة رسمية تعمل في مجال التصميم المعماري والداخلي وتنفيذ المشاريع والخدمات التشغيلية، وتمثل جزءًا من المنظومة المتكاملة لخدمات شركة العزب، وتهدف إلى إدارة أعمال الصيانة والتشغيل وإتاحة خدمات حديثة لعملائها وفق أعلى معايير الاحتراف والجودة.
